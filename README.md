# ChatStack - App Cost Estimator

Estimate development costs and hours for a mobile app, web app, or AI solution, scope an MVP, and generate a software PRD with user stories, requirements, and a technical specification.

Install this plugin in Cursor, Claude, or Grok. No account or API key is required. The plugin connects only to the public interview server at https://mcp.chatstack.app/mcp.

Ask for an app cost estimate, an MVP scope, or a software PRD. ChatStack asks you to choose Review each step or Run it for me, then returns stories, requirements, a technical specification, and an indicative development estimate.

Submitting a completed PRD emails the pack to the confirmed address and creates a ChatStack portal project. Estimates include assumptions and exclusions and are indicative, subject to project review.
